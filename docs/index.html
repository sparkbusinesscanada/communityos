  How the LLM is used
  
One call, wrapped on both sides by plain Apex

  

    
Apex
Gather
Parties, visits, notes and balances for the household.

    
Apex
Mask
Names become tokens. Children's details are never sent.

    
Anthropic API
Claude
Sonnet 5 through a Named Credential, with a JSON schema for the reply.

    
Apex
Check
Unknown tokens dropped, contact details blocked, sources required.

    
Staff
Confirm
Names restored on screen. A person decides what to act on.

  






  Guardrails
  
Minimal by design, applied on every call

  

  

    
LayerWhat is enforced

    
      
Data inPseudonymous tokens; no children's details, birthdays or allergy flags; phones and emails redacted

      
PromptRecord text is data, never instructions; a glossary of booking stages; prompts versioned

      
OutputJSON schema with one required key per question; at most three suggested tasks; one retry if a reply comes back empty

      
Cost200 calls a day and US$25 a month, with every call logged

      
PeopleStaff confirm every action; the AI never contacts a customer

      
SecretsThe API key lives in a Salesforce External Credential, granted by permission set
